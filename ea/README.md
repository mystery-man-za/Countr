# ScalarAI Gateway Expert Advisor (MQL5)

Ready-to-compile Expert Advisor source file for MetaTrader 5: `ScalarAI_Gateway_EA.mq5`.

## Compilation
- Open in MetaEditor 5 (F4 in MetaTrader 5)
- Press F7 (Compile)
- Zero external library dependencies required.
- Place in MT5 folder: `MQL5/Experts/`

## WebRequest Setup
In MT5: Tools -> Options -> Expert Advisors:
- Check "Allow WebRequest for listed URL"
- Add: `http://127.0.0.1:3000` (or your hosted platform domain)
